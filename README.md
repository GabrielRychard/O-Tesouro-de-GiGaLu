# O-Tesouro-de-GiGaLu
RPG de turnos em Python (tkinter): monte uma party com Guerreiro, Mago, Sacerdote e Arqueiro e enfrente 5 hordas até o dragão Tiamat. Cada herói tem ações com mana e recarga, cenários por horda e sprites em pixel art originais gerados com Pillow. Tem fogos e baú de tesouro na vitória. Feito pelo grupo GGL.
